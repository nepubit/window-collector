# Window Collector

マルチディスプレイ環境で、開いているウィンドウを指定したディスプレイに一括移動する Windows 用ツールです。

## 主な機能

- ウィンドウ一覧から選択して、任意のディスプレイへ一括移動
- 新しく開いたウィンドウの自動移動（アプリ別記憶／固定先）
- Windows スタートアップ登録（OS 起動時に自動開始）
- システムトレイ常駐
- ダーク／ライト テーマ切替

## 動作要件

- Windows 10 / 11 (64bit)
- .NET Framework 4.8（Windows 10/11 に標準搭載）
- マルチディスプレイ環境

## ダウンロード

[Releases ページ](../../releases) から最新の `WindowCollector.exe` をダウンロードしてください。
インストール不要、単一の exe を実行するだけで動作します。

## 使い方

1. `WindowCollector.exe` を任意のフォルダに置いて実行
2. 左の「ディスプレイ配置」で移動先ディスプレイをクリック
3. 右のウィンドウ一覧で移動したいウィンドウにチェック
4. 「移動実行」ボタンを押す

自動移動を有効にすると、新しく開いたウィンドウが自動的に指定ディスプレイへ移動します。

## 自動移動のモード

左下の「自動移動」パネルで、新規ウィンドウをどこへ動かすかを 2 つのモードから選べます。
（どちらも、トグルスイッチを ON にしたときだけ動作します。手動の「移動実行」ボタンには影響しません）

### ◉ アプリ別記憶

アプリごとに「最後に手動で移動した先のディスプレイ」を覚えておき、
次に同じアプリの新規ウィンドウが開いたら、その記憶した先へ自動で移動します。

- 記憶は **「移動実行」ボタンを押したとき** に作られます
- アプリごとに違う行き先を持てます
  （例：Chrome は Display 2、Slack は Display 3、エディタは Display 1）
- 何個のアプリを記憶しているかは「記憶: N アプリ」に表示されます
- 一度も移動したことのないアプリは、自動移動の対象外（その場に開いたまま）

「**アプリごとに定位置を決めて、いつもそこに集めたい**」使い方向けです。

### ○ 固定先: D*n*

アプリの種類に関係なく、**新規ウィンドウをすべて 1 つのディスプレイへ** 集約します。

- `D1` と書かれたチップをクリックするたびに `D1 → D2 → D3 → …` と切り替わります
- どのアプリでも開いた瞬間に指定ディスプレイへ吸い込まれます

「**作業中だけ、新しいウィンドウは全部このモニタに集めたい**」使い方向けです。

### どちらを選べばいいか

| やりたいこと | おすすめ |
|---|---|
| アプリごとに定位置を決めたい | アプリ別記憶 |
| とにかく全部 1 つのモニタに集めたい | 固定先 |
| 一時的にメインモニタへ集約したい | 固定先 |
| 普段使いの設定 | アプリ別記憶 |

## 設定ファイル

設定は以下に自動保存されます。exe を移動しても設定は引き継がれます。

```
%LOCALAPPDATA%\WindowCollector\settings.txt
```

## 初回起動時の SmartScreen 警告について

このアプリにはコード署名が付いていないため、初回起動時に
「Windows によって PC が保護されました」という警告が表示されることがあります。
これは未署名アプリ全般に出る警告で、ウイルスを意味するものではありません。

回避手順:

1. 警告画面で **「詳細情報」** をクリック
2. **「実行」** ボタンをクリック

一度実行すれば、以降は警告されません。

## アンインストール

1. スタートアップ登録している場合は、アプリ内で OFF にする
2. `WindowCollector.exe` を削除
3. `%LOCALAPPDATA%\WindowCollector` フォルダを削除

## 注意事項

- exe を別フォルダに移動した場合、スタートアップ登録は無効になります。移動後に再度 ON にしてください。
- 一部のシステムウィンドウ（タスクバー等）は移動対象外です。
- ウイルス対策ソフトが誤検知する場合は、除外リストに `WindowCollector.exe` を追加してください。
